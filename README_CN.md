## 简介

E_start 是一款紧凑型谐波减速赤道仪，主要面向轻型天文摄影和便携观测场景。  
设计目标是：

- 低成本：CNC + 3D 打印混合制造 BOM 控制在 1500 元人民币以内
- 紧凑：主体框架尺寸 119 × 120 × 113 mm
- 高减速比：1:300，适合步进电机高精度跟踪
- 易供电：支持 USB PD 供电，适合户外使用

> 注意：当前阶段未进行完整的载重和导星精度测试，相关数据后续补充。

## 硬件组成
- 采用 S14 谐波减速器 + 同步轮减速机构，总减速比 1:300
- RA 轴配备电磁制动器，断电时自动锁紧，防止意外转动
- 2 个 17HM15-0904S 步进电机（NEMA17，42mm）
- 专为本项目设计的紧凑型 ESP32 控制板

## 软件与功能
- 固件：OnStepX
- 供电：支持 USB PD 协议，自动协商电压，默认请求 12V，可通过 Web 界面调整 PD 档位

## 安全注意事项

- 测试时请勿将手靠近运动中的机构
- 断电后 RA 轴电磁制动器可能释放，注意防止望远镜突然转动
- 使用 USB PD 供电时请确保电源功率足够且线材质量可靠
- 户外使用注意防水、防尘
